# Real Mac walkthrough captures

These are screenshots from an actual VS Code and Microsoft Office walkthrough on a
Mac Studio, captured September 6, 2026. They are not generated illustrations or
reconstructed application screens. JPEG encoding was normalized for distribution;
application content was not redrawn. The decorative repository banner is separate.

The demonstration used a newly cloned public repository, a clean VS Code profile,
and fictional data. An approved Claude connection was already configured, and the
property-tax marketplace had already been added. Those two setup steps are not
represented as fresh sign-in or marketplace-add tests. Plugin installation was
local to the demonstration project. Other marketplace entries visible in the UI
are not required by the course.

Only reviewed application windows and fictional documents belong here. Office
recent-file lists, credentials, remote session URLs, personal conversations, and
unrelated work windows are excluded. Public workbook copies have neutral author
metadata and omit Excel's stored local directory. Raw capture material is not part of this repository.

Number gaps reflect omitted or redundant captures. Each README image has a text
caption and the associated request remains available as a copyable code block.
Mac screenshots illustrate the course; Windows keys and file-opening differences
are written in the guide. No Windows desktop validation is claimed.

VS Code, Claude Code, and Microsoft Office interfaces belong to their respective
owners. Screenshots are included to explain the actual educational workflow.
